# Dəvətnamə Studio

GitHub Pages üçün hazır web dəvətnamə kataloqu.

## Quruluş
- `index.html` — əsas kataloq
- `assets/style.css` — dizayn
- `demos/` — nümunə dəvətnamələr

## GitHub Pages
1. Faylları GitHub repository-yə yüklə.
2. **Settings → Pages** bölməsinə keç.
3. **Deploy from a branch** seç.
4. Branch olaraq `main`, folder olaraq `/ (root)` seç.
5. Save et.

Sonra GitHub sənə saytın linkini verəcək.

## Yeni nümunə əlavə etmək
`demos/` qovluğuna yeni HTML əlavə et və `index.html` daxilində yeni `.card` yarat.
